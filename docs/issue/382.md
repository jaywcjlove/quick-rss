MangoDisk：开源的深度磁盘清理工具，Tauri 应用，支持 macOS 和 Windows
===

<img alt="MangoDisk" src="https://github.com/user-attachments/assets/d622f70b-252c-46f7-8919-4829b11bc0c0" />

一款基于 Tauri 开发、支持 macOS 与 Windows 的开源深度磁盘清理工具，可深度扫描系统缓存、开发构建垃圾、检索大文件与重复文件，支持软件连带残留彻底卸载，并提供磁盘占用可视化分析，兼顾普通用户与开发者需求，源码完全开放，操作安全可控。

👉 https://github.com/harry0703/MangoDisk

[投稿] ChatGPT Plus / Pro 与 Codex 中文开源指南
===

一份采用 MIT 许可证的中文实用指南，面向没有海外银行卡、需要为 ChatGPT 与 Codex 选择 Plus / Pro 的用户。内容覆盖 ChatGPT 订阅与 OpenAI API 计费边界、Plus 与 Pro 5x / 20x 的使用场景、国内支付路径比较、付款前核验、订单查询与账号凭证安全，并持续标注信息核验日期。利益相关：该仓库由 AIXiamo 运营方维护，文中包含 AIXiamo 的第一方服务说明与链接；项目不是 OpenAI 官方资料。

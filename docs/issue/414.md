Tabularis - 开源桌面 SQL 工作区，内置 3 种数据库驱动
===

<img alt="Tabularis" src="https://github.com/user-attachments/assets/4c9a1708-0e31-44c6-99d6-fbfecdc9cf27" />

开源桌面 SQL 工作区，内置 3 种数据库驱动，附带 16 个预装插件，支持 SQL Server、DuckDB、ClickHouse 以及 Redis

https://github.com/user-attachments/assets/c13bd72d-a75d-4cdc-a29c-fb8ebb5b7ae8?title=Tabularis&rehype=video

内置 MCP 服务器，可对接 Claude、Cursor、Devin；支持 SQL 笔记本与可视化执行计划

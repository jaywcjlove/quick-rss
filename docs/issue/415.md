[投稿] bushaoxin：万物皆可不烧心的 Claude Code Skill
===

<img  alt="不烧心文学" src="https://github.com/user-attachments/assets/d0ba2439-0f15-41bd-a6d5-98383129e7dd" />

bushaoxin（不烧心文学）：把红果短剧 AI"良心掌柜"的高同质化台词提炼成万能公式的 Claude Code Skill。装上后 AI 用"贵是贵了点，但用了不烧心"的规矩体写文案、评价事物、回怼、唠嗑，四档火候可调，喊"太烧了"自动降档。纯 prompt 零依赖，兼容 Claude Code / claude.ai / Codex，MIT 开源。

👉 https://github.com/eatmoreduck/bushaoxin

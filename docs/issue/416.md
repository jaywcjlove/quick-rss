macOS 聊天悬浮窗助手。对方消息一进来，悬浮窗立刻给出真实意图（8 类零样本 86.4%）、风险分级（0-9）和候选回复，点「填入」进输入框，发送永远手动。纯只读（截图 + OCR / 系统文本接口，不注入不 hook 不解密数据库），判断层本地 2B 小模型可完全离线，生成层支持 DeepSeek / 智谱 / Ollama。MIT 开源，仅支持 Apple Silicon + macOS 13+。

[投稿] Color Genius：拖 RGB 滑块还原颜色的色感测试游戏
===

<img  alt="Color Genius" src="https://github.com/user-attachments/assets/8322cea2-2ee1-495a-8a21-c3fd3c864aab" />

Color Genius 是一个测色感的网页小游戏：屏幕给出一个颜色，你拖 RGB 滑块还原它，越接近分越高。有多个难度，成绩可以上全球排行榜。免费、免注册，手机和电脑都能玩，适合设计师和前端练眼力。

关联说明：项目方自荐，我是作者。

👉 https://colorgenius.art/

[投稿] DockGo Mac 窗口切换工具
===

Mac 的 Command-Tab 切换单位是「应用」，不是「窗口」。浏览器开了十几个窗口、微信和飞书各两个聊天、Xcode、Finder、备忘录混在一起时，你切到了应用，却还没切到窗口。

AltTab、DockDoor、DockGo 都是来修这最后半步的，也都给出了实时窗口缩略图、都能捞起最小化和跨桌面空间的窗口。**真正的区别不在功能清单，而在「第一下按什么」。**

- **AltTab**：一个全局快捷键，列出系统里所有窗口，像 Windows 的 Alt+Tab；
- **DockDoor**：增强原生 Dock，鼠标悬停图标看预览，外加一个 ⌥+Tab 全局切换器；
- **DockGo**：给每个常用应用绑定一个专属全局快捷键，按住看见这个应用的全部窗口，松开直达。

一个是「全局列举」，一个是「Dock 增强」，一个是「一应用一热键」。下面按真实使用场景拆。

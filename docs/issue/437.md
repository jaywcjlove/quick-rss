[投稿] 3D Solar System Simulator：浏览器里的免费 3D 太阳系模拟器
===

3D Solar System Simulator 是一个在浏览器里打开就能用的 3D 太阳系模拟器：可以绕着太阳和八大行星自由转动、缩放视角，调快或调慢时间看各行星公转，切换"真实距离"和"真实比例"感受教科书示意图与实际尺度的差别，还能"登陆"月球和火星表面走一走。基于 Three.js，免费、免注册、不用下载，适合给孩子讲天文或课堂投屏演示。界面目前以英文为主。

[投稿] FaviconDL：输入网址下载任意网站的全部图标
===

FaviconDL 输入任意网址，找出网站实际发布的 ICO / PNG / SVG / Apple Touch Icon / manifest 图标，预览后直接下载；另有免 Key JSON API、图片转 favicon、批量获取。免费免注册，适合做书签页、导航站和链接预览。

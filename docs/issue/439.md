[投稿] ReadGZH：把微信公众号文章转成 AI 可读取的页面
===

ReadGZH 粘贴微信公众号文章链接，生成更适合 AI 读取的精简页面；提供 REST API 与 MCP。它先解决「AI 能不能拿到正文」，不替你做总结。有免费额度，转换受原文可访问性影响。

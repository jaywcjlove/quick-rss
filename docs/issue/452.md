Stela - 让普通 Intel / AMD PC 运行 Apple Silicon 版 macOS 的实验性开源项目。
===

让普通 Intel / AMD PC 运行 Apple Silicon 版 macOS 的实验性开源项目。

它通过 ARM64 指令翻译、Apple Silicon 硬件建模以及 NVIDIA GPU 的 Metal 驱动，让普通 x86-64 PC 能够尝试运行原本为 Apple Silicon Mac 编译的 macOS。

<img alt="Stela" src="https://github.com/user-attachments/assets/c74d9508-433a-4b53-8af2-42609a96ea82" />

与传统 Hackintosh 不同，Stela 并不是运行 Intel 版 macOS，而是尝试在 x86-64 硬件上运行 ARM64 版 macOS。目前它将自身模拟为一台 Apple M2 Mac mini。

这是一个相当大胆的尝试，涉及 CPU 跨架构指令翻译、硬件模拟和 GPU 驱动等底层技术。

如果未来能够成熟，或许能让更多非 Apple 硬件运行 Apple Silicon 版 macOS。

不过，项目目前仍处于早期开发阶段，性能和硬件兼容性都有限，暂时还不能作为日常使用的 PC 安装 macOS 方案。

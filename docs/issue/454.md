[投稿] Lyrimuse：开源免费的 Mac 桌面歌词，支持 QQ 音乐、网易云等国内播放器
===

开发者自荐。Lyrimuse 是 Mac 上的桌面歌词软件，开源免费（GPL-3.0）。我以前一直用 LyricsX，它 2022 年之后就不更新了，也不支持国内的播放器，就自己写了一个。

它跟着正在放的歌逐字显示歌词，可以挂在桌面上，也能放进菜单栏、刘海下面的灵动岛或者完整的歌词窗口。Apple Music、Spotify、QQ 音乐、网易云、酷狗这些都能用，浏览器里的网页播放器也行，一共二十多款。歌词从十几个源里找，自动挑跟这首歌的版本对得上的那一份，日语歌能标假名，粤语歌能标粤拼。

<img alt="Lyrimuse" src="https://raw.githubusercontent.com/Yudaotor/lyrimuse/main/docs/images/hero-surfaces.zh-CN.jpg" />

需要 macOS 14 以上，Apple 芯片和 Intel 都能用。安装包在 GitHub Releases，也可以用 Homebrew 装：

```bash
brew tap yudaotor/lyrimuse
brew trust --cask yudaotor/lyrimuse/lyrimuse
brew install --cask lyrimuse
```

App 没有做 Apple 公证，手动下载的话第一次打开要去「隐私与安全性」里点一下「仍要打开」，用 Homebrew 装就没有这一步。

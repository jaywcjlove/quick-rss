[投稿] Builderoom：独立开发者、设计师与创客的作品展台
===

Builderoom 收的是个人和小团队做出来的作品：网页应用、小程序、App、桌面软件、浏览器扩展、命令行工具、skill、智能体、开源库、设计作品。找东西的人不用知道名字，用一句话或一段语音说出需求，AI 就从站内作品里挑出合适的几款，并说明为什么推荐。做东西的人贴一个链接（官网、GitHub 仓库、应用商店页面或 npm / PyPI 包），AI 会把介绍、功能和截图整理好，核对后提交，免费，人工审核后上架。界面有中文和英文。

CrossDesk：跨平台远程桌面控制软件，可以让你通过 Mac、Windows、Linux、浏览器、手机甚至终端，远程查看和控制其他电脑。
===

CrossDesk 不只是远程桌面软件，更像是一个跨平台远程设备管理与控制平台。

它类似 TeamViewer、AnyDesk、RustDesk，但它还有一个比较特别的功能：DeskHub，可以同时查看和控制多台电脑，形成一个远程桌面控制墙。

<img alt="CrossDesk" src="https://github.com/user-attachments/assets/4db5a62d-ad80-43a2-b30a-f50cb62e2386" />

最值得关注的三个方向是：

☑️ DeskHub：同时管理多台电脑，适合多设备开发和测试。  
☑️ Terminal Controller：通过终端控制远程桌面，适合开发者。  
☑️ Agent / MCP：让 AI Agent 可以直接操作远程电脑。  

尤其是 MCP 这一块，意味着 CrossDesk 有机会成为 AI Agent 操作远程 macOS、Windows 和 Linux 设备的一个基础工具。

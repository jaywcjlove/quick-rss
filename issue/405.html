[投稿] PinAtlas：通用芯片引脚查询与可视化工具

PinAtlas 是一个开源的通用芯片引脚查询与可视化工具，输入芯片型号即可查看封装引脚图，点击引脚可查看复用功能与 AF 号。项目目标是通用，不限于 STM32，后续计划支持 ESP32 / RP2040 / GD32 / CH32，前端只依赖统一 JSON 契约，不做厂商判断。

核心亮点：

数据规模：2781 个型号 / 27 个家族分片，前端按需拉取，首屏仅加载 9 KB 清单 + 当前家族分片

封装引脚图：SVG 绘制，支持 quad（QFP/QFN）、dual（SOP/TSSOP）、grid（BGA/WLCSP）三套布局；字号由几何反推，密脚封装（如 LQFP208）也不会压叠

交互体验：悬停看 pad 名与前 3 个功能、点击选中、键盘 Tab 聚焦 + Enter/Space 选中

过滤与高亮：支持 GND / 5V / 3V3 / GPIO / UART / I2C / QSPI / I2S / JTAG / PDM / PWM 等功能类别高亮，带匹配计数

引脚详情：主名/别名/重映射标注、变体切换、按外设分组的复用功能 + AF 号

其他：状态进 URL 可分享、深浅主题、PWA 离线

技术栈：Nuxt 4.5 + Vue 3.5 + TypeScript、Tailwind v4 + shadcn-vue、Pinia、@vite-pwa/nuxt

数据来源：主源 LibrePCB/stm-db，AF 号由 embassy-rs/stm32-data-generated 补全；上游数据源自 ST 官方文档，版权归 STMicroelectronics。代码 MIT 许可。

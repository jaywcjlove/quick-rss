[投稿] MakeMovie：从一段文字到一部成片的开源 AI 影视生产线（Next.js）

市面上的 AI 视频工具大多交付「一段素材」：输入提示词，吐回一条几十秒的片段。但把一个故事真正变成 「一部片子」，中间隔着剧本改编、分镜、角色与场景资产、配音、配乐、剪辑合成、质检、交付——每一环 都要人肉拼接四五款工具，素材在各家网页里来回搬运，最后还算不清哪次调用花了多少钱。

MakeMovie 把这条生产线做成了一个可以自己托管的开源平台（Apache-2.0）。

  • 从原文进、从交付出：上传小说原文或故事设定，自动完成剧本改编 → 分镜 → 角色/场景/道具定妆 → 首帧 → 图生视频 → AI 配音 → 配乐 → 合成母带 → 技术质检 + 模型视觉审计 → 交付， 每一步可查看、可编辑、可追溯到产生它的那次模型调用。
  • 交付不止一个 MP4：每个分集同时打包 SRT 字幕与 EDL / FCPXML / OTIO 剪辑清单， 在 Premiere Pro 或 DaVinci Resolve 里打开就能接着剪，而不是被锁在控制台里。
  • 模型可插拔：九个能力槽位对应生产线的九道工位，阿里百炼 / 可灵 / 火山 Seedance / OpenAI / Google / Anthropic / 任意 OpenAI 兼容端点都能接，一个百炼连接就够点亮全链；一键补齐缺口。
  • 声音链是完整的：本地内嵌 Qwen3-TTS（MLX）做音色克隆——给角色一段参考音频就能配音； 逐镜氛围声、配乐、声音工坊降噪洗涤，不依赖任何云 TTS。
  • 每一帧都有账：生成任务幂等可恢复（崩溃续查不重复计费）、逐镜质检问题队列、 按物理量记账的用量台账、RBAC 与审计日志。
  • Docker 一条命令自托管：内置示例项目，零 API key 就能完整试跑一遍流水线。
